# Repository instructions

This repository is the public research package for boundary-contact order in simplex lifts.

## Source of truth

- `paper/boundary_contact_order.tex` is the manuscript source.
- `docs/theorem.md` is the concise public statement of the proved results.
- `docs/literature-audit.md` separates established results, proposed contributions, and unresolved novelty risks.
- `verification/` contains transcription checks. The manuscript proofs remain authoritative.

## Research discipline

- State smoothness, nonnegativity, support, and contact-order hypotheses explicitly.
- Keep universal landscape-preservation claims separate from convex-objective characterizations.
- Treat numerical and symbolic checks as diagnostics, never as proofs.
- Cite primary papers or authoritative monographs. Record incomplete searches as incomplete.
- Do not claim peer review, publication, exhaustive novelty, or algorithmic convergence without direct evidence.

## Repository workflow

- The canonical branch is `master`.
- Keep generated LaTeX files and local submission packages untracked.
- A compiled PDF may be tracked only after a full build and rendered-page inspection outside resource-constrained mode.
- Public tracked files use neutral paths and reproducible commands.
